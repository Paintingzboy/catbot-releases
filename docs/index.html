Fitur

Bukan sekadar robot, tapi teman

Ngobrol dengan AI

Tahan tombol robot, bicara, dan CatBOT menjawab. Pilih AI favoritmu: Gemini, Groq, ChatGPT, Claude, dan lainnya.

Mata yang hidup

Mata OLED berkedip, melirik, tertawa, dan ikut mengikuti bola, lemon, atau susu yang kamu geser di layar.

Agenda & pengingat

Catat jadwal kuliah dan deadline. Robot mengingatkan saat waktunya tiba, dan bisa membacakan agenda hari ini.

Game seru

Menu di robot

Cara Pasang

Pilih sesuai HP-mu

Gratis untuk Android dan iPhone. Pastikan robot CatBOT sudah menyala sebelum menyambungkan.

Android Disarankan

Aplikasi lengkap: tetap aktif saat layar terkunci & update otomatis.

  1. Ketuk Download untuk Android.
  2. Buka file catbot.apk dari notifikasi unduhan.
  3. Kalau diminta, izinkan "Instal aplikasi tidak dikenal", lalu ketuk Instal.
  4. Buka CatBOT, ketuk ikon Bluetooth, lalu Hubungkan.
Download untuk Android

iPhone / iPad Versi web

Safari & Chrome di iPhone belum bisa Bluetooth, jadi pakai browser gratis Bluefy.

  1. Pasang Bluefy – Web BLE Browser dari App Store (gratis).
  2. Salin link versi web di bawah, lalu buka di Bluefy.
  3. Ketuk ikon Bluetooth, pilih CatBot-BLE, lalu Pair.
  4. Biarkan Bluefy tetap terbuka selama memakai robot.
